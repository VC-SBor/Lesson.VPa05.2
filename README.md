# PassKeep

Консольный менеджер паролей на Python с шифрованием **Fernet** и хранением в **SQLite3**.

---

## Особенности

- **Мастер-пароль** хранится в виде соли + хеша `PBKDF2-HMAC-SHA256` (200 000 итераций). Сам пароль в базе не сохраняется.
- **Пароли записей** шифруются симметричным шифром Fernet (AES-128-CBC + HMAC-SHA256). Ключ лежит в отдельном файле `.key`.
- **Блокировка ввода** — после 5 неверных попыток ввода мастер-пароля программа блокируется на 60 секунд. Счётчики хранятся в БД, поэтому перезапуск не снимает блокировку.
- **Генератор паролей** использует криптографически стойкий ГСЧ `secrets` и исключает легко перепутанные символы (`il1LIoO0`).
- **Копирование в буфер** через `pyperclip` с автоматическим fallback на системные утилиты (`clip.exe`, `pbcopy`, `xclip`/`xsel`/`wl-copy`).
- **Настройка пути** к хранилищу — параметр `--home PATH` или переменная окружения `PASSKEEP_HOME`.

> ⚠️ **Внимание:** поле `login` хранится в открытом виде (в таблице SQLite). Если требуется полная конфиденциальность логина — используйте флаг `--no-print` вместе с `--copy`.

## Установка

### Системные требования

- **Python 3.12+**
- Виртуальное окружение (рекомендуется)

### Пошагово

```bash
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать
# Windows (cmd):
venv\Scripts\activate
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux/macOS:
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Проверить установку
python main.py --version
# PassKeep 1.0.0
```

## Первый запуск

При первом запуске программа создаст каталог хранилища, файл ключа `.key` и запросит мастер-пароль:

```bash
python main.py init
```

Мастер-пароль должен содержать **не менее 8 символов** без пробелов в начале/конце. Он нужен для разблокировки каждого запуска программы.

## Команды

### `init`

Создать базу данных и мастер-пароль (вызывается автоматически при первом запуске).

```bash
python main.py init
```

### `add` — добавить запись

```bash
# С явным паролем
python main.py add Google --login user@gmail.com --password secret123 --notes "личный аккаунт"

# С генерацией пароля (пустой ввод пароля)
python main.py add GitHub --login dev
```

| Параметр  | Описание                          |
|-----------|-----------------------------------|
| `name`    | Название (обязательно)            |
| `--login` | Логин / email                     |
| `--password` | Пароль (если не указан — спросит) |
| `--notes` | Произвольная заметка              |
| `--copy`  | Скопировать пароль в буфер         |
| `--length`| Длина генерируемого пароля (по умолчанию 16) |

### `get` — получить пароль

```bash
python main.py get Google
python main.py get Google --copy       # без вывода на экран + в буфер
python main.py get Google --no-print   # только метаданные
```

### `list` — список записей

```bash
# Все записи
python main.py list

# С фильтром по названию или логину
python main.py list --filter gmail
```

Пароли **никогда** не выводятся в списке.

### `remove` / `delete` — удалить запись

```bash
python main.py remove Google
python main.py delete Google --yes     # без подтверждения
```

### `new` — генерация пароля

```bash
# Просто сгенерировать и показать
python main.py new --length 20

# Сгенерировать и сразу сохранить
python main.py new --length 20 --save MyBank --login admin

# Без спецсимволов (для систем с ограничениями)
python main.py new --no-symbols --length 16 --copy
```

| Параметр        | Описание                               |
|-----------------|----------------------------------------|
| `--length N`    | Длина пароля (по умолчанию 16)         |
| `--no-digits`   | Без цифр                               |
| `--no-symbols`  | Без спецсимволов                       |
| `--copy`        | Скопировать в буфер обмена            |
| `--save NAME`   | Сразу сохранить в базу под «NAME»      |
| `--login LOGIN` | Логин для сохранения                   |

## Как копировать пароли

### Автоматически (рекомендуется)

Используйте флаг `--copy` с командами `add`, `get` и `new`:

```bash
python main.py add Google --login user@gmail.com --copy
python main.py get Google --copy
python main.py new --length 20 --copy
```

Пароль будет скопирован в буфер обмена. Программа выведет предупреждение:

```
Пароль скопирован в буфер обмена. Не забудьте очистить буфер.
```

### Механизм копирования

1. Сначала используется библиотека `pyperclip` (устанавливается автоматически).
2. Если `pyperclip` недоступен, применяются системные утилиты:
   - **Windows** → `clip.exe`
   - **macOS** → `pbcopy`
   - **Linux** → `wl-copy` → `xclip` → `xsel`
3. Если буфер недоступен, пароль выводится на экран с предупреждением.

### Вручную

Если буфер обмена недоступен (например, в SSH-сессии без X11), пароль можно
взять с экрана: `python main.py get Google` выведет его в строке `Пароль`,
оттуда его можно выделить и скопировать средствами терминала. Чтобы пароль не
попадал в историю команд, не передавайте его параметрами командной строки.

## Структура проекта

```
main.py                     # Точка входа
requirements.txt            # Зависимости
passkeep/
  __init__.py               # Пакет, версия
  __main__.py               # Запуск: python -m passkeep
  app.py                    # Основная логика (класс Vault, разблокировка)
  cli.py                    # CLI-парсер и обработчики команд
  crypto.py                 # Хеширование, Fernet-шифрование, генератор паролей
  storage.py                # SQLite3: таблицы meta и vault
  clipboard.py              # Копирование в буфер (pyperclip + fallback)
  errors.py                 # Иерархия исключений
  paths.py                  # Пути к хранилищу и ключам
```

### База данных (SQLite3)

| Таблица | Назначение                          |
|---------|-------------------------------------|
| `meta`  | Соль, хеш мастер-пароля, счётчики блокировки |
| `vault` | Записи (имя, логин, зашифрованный пароль, заметка, даты) |

Файл хранилища: `~/.passkeep/vault.db`

### Файл ключа шифрования

Файл `.key` содержит 32-байтный ключ Fernet (зашифрованный base64-префикс).
При создании устанавливаются права `0600` (только владелец, где ОС позволяет).

Файл хранилища: `~/.passkeep/.key`

## Безопасность

### Что шифруется

- **Пароли** записей — алгоритм Fernet (AES-128-CBC + HMAC-SHA256). Без файла `.key` расшифровка невозможна.
- **Мастер-пароль** — хеш `PBKDF2-HMAC-SHA256` с 16-байтной случайной солью и 200 000 итераций.

### Что НЕ шифруется

- **Название** записи (`name`) — используется для поиска.
- **Логин** (`login`) — хранится в открытом виде в таблице `vault`.
- **Заметка** (`notes`) — хранится в открытом виде.
- **Временные метки** (`created_at`, `updated_at`).

### Блокировка ввода

После 5 подряд неверных попыток ввода мастер-пароля:

```
БЛОКИРОВКА: Ввод заблокирован. Повторите попытку через 60 сек.
```

Пароль не подходит в течение 60 секунд, даже правильный.

### Коды выхода

| Код | Значение                    |
|-----|-----------------------------|
| `0` | Успех                       |
| `1` | Ошибка (не найдено, дубликат и т.д.) |
| `2` | Неверный мастер-пароль      |
| `3` | Ввод заблокирован (5 неудачных попыток) |
