# PassKeep

Простой консольный менеджер паролей на Python: **SQLite3** для хранения и
**Fernet** (`cryptography`) для шифрования паролей.

Программа работает в интерактивном режиме: запускается одной командой,
сама создаёт хранилище при первом запуске и показывает меню действий.

---

## Установка

Требуется **Python 3.10+**.

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux/macOS:
source venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt
```

Зависимости: `cryptography` (шифрование) и `pyperclip` (копирование в буфер обмена).

---

## Запуск

```bash
python main.py
```

### Первый запуск

Если ещё нет базы данных и файла ключа, программа создаёт их автоматически и просит
придумать пароль входа:

```
Создайте пароль для входа (не менее 8 символов):
Повторите пароль:
Пароль сохранён, аутентификация успешна
```

### Последующие запуски

```
Введите пароль:
```

После **5 неверных попыток** подряд ввод блокируется на **60 секунд**. Счётчик
хранится в базе, поэтому перезапуск программы блокировку не снимает.

## Меню

```
============================
МЕНЕДЖЕР ПАРОЛЕЙ
============================
1. Добавить новый пароль
2. Список всех паролей
3. Получить пароль
4. Удалить пароль
5. Сгенерировать пароль
6. Выход
============================
Выберите действие (1-6):
```

### 1. Добавить новый пароль

Запрашивает название записи, логин и предлагает сгенерировать пароль. Если выбрать
`Y` — открывается диалог генерации (длина 8–64, выбор типов символов, копирование
в буфер). Если `N` — пароль вводится вручную (скрытым вводом).

### 2. Список всех паролей

Показывает названия и логины всех записей. Пароли не отображаются.

### 3. Получить пароль

Показывает название, логин и пароль выбранной записи. Если записи нет —
сообщает «Пароль с таким названием не найден».

### 4. Удалить пароль

Запрашивает подтверждение и удаляет запись.

### 5. Сгенерировать пароль

Генерирует пароль для любых нужд: название записи не запрашивается, в базу ничего
не сохраняется. После генерации предлагает скопировать пароль в буфер обмена.

### 6. Выход

Завершает программу.

## Где хранятся данные

По умолчанию — каталог `~/.passkeep`:

| Файл              | Назначение                                             |
|-------------------|--------------------------------------------------------|
| `vault.db`        | База SQLite: таблицы `meta` и `vault`                  |
| `.key`            | Ключ шифрования Fernet                                 |

Путь можно переопределить переменной окружения `PASSKEEP_HOME`.

---

## Безопасность

- **Пароль входа** не хранится в открытом виде: только случайная соль и хеш
  `PBKDF2-HMAC-SHA256` (200 000 итераций).
- **Пароли записей** шифруются Fernet (AES-128-CBC + HMAC-SHA256). Ключ лежит в
  отдельном файле `.key`.
- **Не шифруются**: название записи, логин и служебные метки времени.

> ⚠️ Если потерять пароль входа или файл `.key`, восстановить сохранённые пароли
> невозможно.

## Структура проекта

```
main.py                     # Точка входа (python main.py)
requirements.txt            # Зависимости
passkeep/
  __init__.py               # Пакет, версия
  __main__.py               # Запуск: python -m passkeep
  cli.py                    # Интерактивное меню
  app.py                    # Логика: разблокировка хранилища, записи, блокировка
  crypto.py                 # Хеширование, Fernet, генератор паролей
  storage.py                # SQLite3: таблицы meta и vault
  clipboard.py              # Копирование в буфер (pyperclip + fallback)
  errors.py                 # Иерархия исключений
  paths.py                  # Пути к хранилищу и ключам
```
